# BoardScoring v5

## Modifications
- bouton **Nouvelle partie** dans l'écran des scores
- ce bouton renvoie directement vers **l'écran de création de partie**
- nouveau logo basé sur l'image fournie

## Mise à jour GitHub Pages
1. Remplacer les anciens fichiers du dépôt par ceux-ci.
2. Committer les changements.
3. Faire un push sur `main`.
4. Attendre 1 à 2 minutes puis recharger le site.
5. Si besoin, supprimer/réinstaller l'app sur l'écran d'accueil pour vider l'ancien cache.
